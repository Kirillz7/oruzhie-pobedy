Управление контентом

Изменения сохраняются в localStorage браузера и сразу применяются на основном сайте.

Вход

Введите пароль администратора. По умолчанию: admin2026 (меняется в js/utils.js, константа ADMIN_PASSWORD).

Генератор QR-кодов

Введите URL или код карточки. Если ввели ID (например, ak12), будет сформирована ссылка на главную с якорем #card=ak12. QR-код генерируется локально, интернет не нужен.

Что закодировать
Быстрый выбор образца

Экспорт данных

Скачайте JSON со всем: пользователи, прогресс, изменённые образцы, вопросы, достижения, тема, звук, фон. Сохраняйте файл в надёжном месте.

Импорт данных

Загрузите ранее сохранённый JSON. Текущие данные будут полностью заменены.

Опасная зона

Полный сброс всех данных. Необратимо.
